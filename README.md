A code-only geolocation agent for make.fun's photo-geolocator-01: it places each street photo at the practice-calibrated geographic prior (57.0 N, 27.0 E) with no model calls, answering all 25 photos deterministically.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:18080 MAKEFUN_PROMPT_FILE=prompt.txt python3 -P -s main.py
```
